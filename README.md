# Cinderhold Bestiary

Interaktívne 3D modely a útoky bossov Drakhaal a The Nameless z Minecraft módu Cinderhold.

Nezávislý fanúšikovský projekt, nie je spojený s Mojang ani Microsoft. Stránka nepoužíva cookies, analytiku ani cudzie servery.

- three.js r160 (MIT), `vendor/three/LICENSE`
- Písma IM Fell English SC a Alegreya Sans (SIL Open Font License 1.1), z Google Fonts
